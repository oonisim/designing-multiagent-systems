# Chapter 13: current code guide

Chapter 13 is primarily governance and design guidance. The repository provides
enforceable controls for some risks, but no complete ethics or compliance system.

## Enforceable controls in the repository

| Risk area | Actual code file |
| --- | --- |
| Tool approval | [`tools/_base.py`](../../picoagents/src/picoagents/tools/_base.py) and [`context.py`](../../picoagents/src/picoagents/context.py) |
| Guardrails, redaction, rate limits, and logging | [`_middleware.py`](../../picoagents/src/picoagents/_middleware.py) |
| Telemetry | [`_otel.py`](../../picoagents/src/picoagents/_otel.py) |

## Section guide

### 13.1–13.2 Ethical and security risks

The book explains the risk model; there is no code that can automatically make
an application ethical or compliant. Convert each risk into an explicit policy,
test, and operational owner.

### 13.3 Controls during execution

Read [`test_tool_approval.py`](../../picoagents/tests/test_tool_approval.py),
then [`tools/_base.py`](../../picoagents/src/picoagents/tools/_base.py) and
[`context.py`](../../picoagents/src/picoagents/context.py). Approval suspends
an action until the application provides a decision.

### 13.4 Observability and guardrails

Read [`test_middleware.py`](../../picoagents/tests/test_middleware.py), then
[`_middleware.py`](../../picoagents/src/picoagents/_middleware.py) and
[`_otel.py`](../../picoagents/src/picoagents/_otel.py). Middleware is the
place to enforce local policy consistently around agent calls.

## Practical order

```text
define prohibited actions → require approval → redact and log → bound runtime
    → test rejection and cancellation paths
```
