## Section guide

### 10.1–10.2 Evaluation-driven development and trajectories

Start with [`test_eval.py`](../../picoagents/tests/test_eval.py). Then read
[`eval/_base.py`](../../picoagents/src/picoagents/eval/_base.py) to identify
what an evaluation run records and [`eval/_runner.py`](../../picoagents/src/picoagents/eval/_runner.py)
to see how targets execute.

### 10.3 Suites, datasets, metrics, and judges

Read [`eval/_dataset.py`](../../picoagents/src/picoagents/eval/_dataset.py),
[`eval/_targets.py`](../../picoagents/src/picoagents/eval/_targets.py), and the
judge implementations in [`eval/judges/`](../../picoagents/src/picoagents/eval/judges/).
Use [`test_eval_scoring.py`](../../picoagents/tests/test_eval_scoring.py) as
the smallest scoring specification.

### 10.4–10.5 Harness and results

Read [`examples/evaluation/`](../../examples/evaluation/) after the tests. Trace
configuration through [`eval/_config.py`](../../picoagents/src/picoagents/eval/_config.py),
execution through `_runner.py`, and results through `_results.py` and `_analysis.py`.

## End-to-end trace

```text
dataset → target → eval/_runner.py → judge → results → analysis
```
