## Section guide

### 11.1–11.2 Optimization loop

Start with [`test_optim.py`](../../picoagents/tests/test_optim.py), then read
[`optim/_spec.py`](../../picoagents/src/picoagents/optim/_spec.py) and
[`optim/_trace.py`](../../picoagents/src/picoagents/optim/_trace.py). They
define what is varied, what evidence is retained, and what outcome is scored.

### 11.3 Failure modes

The book's failure modes span the repository rather than one optimizer: use
Chapter 10 for measurement, Chapter 4 for tools and memory, Chapter 7 for
termination, and approval middleware for actions. The optimizer code does not
replace those controls.

### 11.4 Practical optimization

Read [`examples/optimization/`](../../examples/optimization/), then trace a
reflective strategy in [`optim/_reflective.py`](../../picoagents/src/picoagents/optim/_reflective.py).
Compare every candidate against the held-out suite before adopting it.

## End-to-end trace

```text
evaluation evidence → optim/_spec.py → optim/_trace.py
    → optimizer → held-out evaluation
```
