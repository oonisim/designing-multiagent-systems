# Chapter 12: current code guide

Chapter 12 covers distributed-agent protocols. The current repository implements
MCP integration. It does not contain an A2A implementation corresponding to the
book's A2A discussion.

## Section guide

### 12.1–12.2 Protocol boundary and MCP

Start with [`test_mcp_integration.py`](../../picoagents/tests/test_mcp_integration.py),
then read [`_config.py`](../../picoagents/src/picoagents/tools/_mcp/_config.py)
and [`_client.py`](../../picoagents/src/picoagents/tools/_mcp/_client.py). They
define the connection and client lifecycle.

### 12.3 Tool discovery and execution

Read [`_integration.py`](../../picoagents/src/picoagents/tools/_mcp/_integration.py)
and [`_tool.py`](../../picoagents/src/picoagents/tools/_mcp/_tool.py). They turn
remote MCP capabilities into the framework's normal tool contract.

### 12.4 Practical use and safety

Read [`examples/mcp/`](../../examples/mcp/) and the MCP tests. Apply the same
tool approval, least-privilege, and observability controls used for local tools.

### A2A

No A2A source, example, or test is present in this repository. Treat that part
of the chapter as protocol background rather than a guide to local code.

## End-to-end trace

```text
MCP configuration → _client.py → _integration.py → _tool.py → Agent tool loop
```
