# Chapter 15: current code guide

Chapter 15 assembles an SWE agent. Treat it as an application to reverse
engineer, not the starting point for learning the framework: it combines tools,
workspace state, memory, compaction, and verification.

## Section guide

### 15.1–15.2 Agent architecture and tools

Start with [`README.md`](../../examples/agents/swe_agent/README.md), then read
[`agent.py`](../../examples/agents/swe_agent/agent.py). Identify every supplied
tool before reading its implementation in
[`_coding_tools.py`](../../picoagents/src/picoagents/tools/_coding_tools.py).

### 15.3 Prompts, context, and memory

The application instructions live in [`agent.py`](../../examples/agents/swe_agent/agent.py).
Read them with [`_context_tools.py`](../../picoagents/src/picoagents/tools/_context_tools.py),
[`_memory_tool.py`](../../picoagents/src/picoagents/tools/_memory_tool.py), and
[`compaction.py`](../../picoagents/src/picoagents/compaction.py). These define
what the agent can inspect, retain, and reduce.

### 15.4–15.5 Completion and review

Read [`_hooks.py`](../../picoagents/src/picoagents/_hooks.py) for deterministic
work around an agent run. Use Chapter 10's evaluation framework to assess code
changes; a successful conversation is not evidence that a patch is correct.

## End-to-end trace

```text
SWE README → agent.py → tools/_coding_tools.py → context and memory tools
    → agent loop → hooks and evaluation
```

Run this example only in a disposable workspace or with explicit approval for
the actions it can perform.
